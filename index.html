Full Adder Circuit Lab

A 1-bit Full Adder adds A, B and a carry-in (Cin). It gives a Sum bit and a carry-out (Cout). Blue wires carry a 1.

Truth table

Equations

Sum = A XOR B XOR Cin

Cout = (A AND B) OR (Cin AND (A XOR B))

Sum is 1 when an odd number of inputs are 1. Cout is 1 when at least two inputs are 1.

Adder Architecture: RCA vs CLA

Ripple Carry Adder (RCA)

Full Adders are connected in series. Each stage waits for the carry from the stage before it, so delay grows with bit width.

FA₃◀ c₃FA₂◀ c₂FA₁◀ c₁FA₀◀ Cin

Carry Lookahead Adder (CLA)

Generate (G = A·B) and Propagate (P = A⊕B) signals feed a lookahead unit that works out the carries together, instead of waiting for them one by one.

Bits Aᵢ, Bᵢ▶Generate / Propagate
Gᵢ = Aᵢ·Bᵢ, Pᵢ = Aᵢ⊕Bᵢ▶Carry-lookahead unit
C₁ = G₀ + P₀·C₀ …▶Sum bits
Sᵢ = Pᵢ ⊕ Cᵢ
FeatureRCACLA
StructureFull Adders in seriesG/P logic plus a lookahead unit
Carry handlingPassed stage by stageComputed with generate and propagate logic
SpeedDelay grows with the number of bitsCan reduce carry delay
Hardware and wiringSimple, relatively lowMore logic, wiring and area
Design complexityLowHigher (depends on the implementation)

Trade-off: simplicity and cost (RCA) against speed (CLA). Practical processors may use advanced or hybrid adder structures, so neither is universal.

Binary Reference

Binary is base 2. It uses only the digits 0 and 1. Place values, from right to left, are 2⁰ = 1, 2¹ = 2, 2² = 4, 2³ = 8, 2⁴ = 16. Click a bit to flip it.

Example: 1101₂ = 8 + 4 + 0 + 1 = 13₁₀.

Runs fully in the browser (plain HTML, CSS, JavaScript). The arithmetic engine (Arith) is separate from the interface code. Labs support unsigned inputs of 1 to 8 bits. Subtraction requires A ≥ B; the ALU shows wrap-around with a borrow flag.
